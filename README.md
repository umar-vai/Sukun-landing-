# SukunLife — ৪০ দিনের জাদু থেকে সুরক্ষা চ্যালেঞ্জ

Responsive single-page landing page for SukunLife's 40-day protection challenge.

## Included in the landing page

- SukunLife brand palette and typography
- Evergreen 40-day structure so registration can continue throughout October
- No festival-specific naming or fixed October 10–November 8 date range
- Registration fee: ৳485
- 3 webinars
- 3 live Q&A sessions
- 1 online/offline consultation (stated value ৳1500)
- Planner, tracker, notes and seminar gifts
- Old-patient bonus: e-book, tracker, special amal and audio resources
- Responsive mobile design with sticky CTA
- Lightweight reveal animations
- FAQ section
- WhatsApp registration flow to SukunLife booking number

## Run locally

Open `index.html` directly in a browser or serve the repository with any static web server.

## Publish

This is a static page. It can be published from the repository root using GitHub Pages, Netlify, Vercel, Cloudflare Pages, or any standard static host.
